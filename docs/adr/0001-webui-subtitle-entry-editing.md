# WebUI 以字幕条目为统一编辑单位

2026-10-15：首版 WebUI 的字幕总览轨和说话人轨道展示同一批字幕条目；说话人轨道不是具有独立起止时间的另一套片段。用户在两处修改同一条字幕时，其正文、时间和说话人归属同步变化；上下换轨表示修改该条字幕的说话人归属。

这是在“单条字幕的多种视图”和“字幕、说话人各自维护独立时间段”之间的选择。前者符合现有一条字幕一个说话人标注的数据契约，也避免校对、撤销和导出时产生互相矛盾的两套时间与归属。

首版面向本机单人字幕校对：视频轨始终锁定在原片时间轴，字幕允许文字、归属、起止时间、拆分、合并和增删编辑。编辑单位是字幕条目，视频剪辑引起的媒体重排及时间映射不属于本次选择的编辑模型。

合法的时间重叠不通过推移或裁切其他条目消除；同轨重叠采用轨内错层显示。浏览器兼容性需要的预览副本同样保持原片时间基准，不能用推理用的紧凑拼接视频替代编辑时间轴。
