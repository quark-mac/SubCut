# 编辑工程保存与字幕导出分离

2026-10-15：WebUI 将一份视频和一份工作字幕组成独立编辑工程。“保存”记录工程中的字幕、说话人配置与媒体路径，“导出”生成交付字幕。导入文件是来源，保存工程不直接覆盖它。

直接将 SRT 作为唯一保存对象虽然简单，却无法完整表达轨道颜色、顺序及可用的来源信息。独立工程保存是继续校对的依据，字幕导出则遵循相应格式的表达能力；同一视频可以用于多个相互独立的工程。

工程默认位于 `webui/workspace/<工程ID>/`，视频按原路径引用，预览副本存于工程目录；素材移动后可重新定位。工程支持自动保存与手动立即保存，但保存不清空当前撤销历史；重新打开工程从持久化的当前状态开始新的撤销历史。
