# WebUI 字幕编辑器设计记录

日期：2026-10-15。状态：用户已整体确认，设计定稿。

本记录汇总 `/grill-with-docs` 访谈中的产品、交互和交付约定，供后续细化工程 schema、接口与实现任务使用。

## 1. 定位与参考

- 根目录 `webui/` 下的本机单人字幕编辑器：导入视频和字幕 → 播放校对 → 编辑 → 保存工程 → 导出字幕。
- 一个编辑工程对应一份视频和一份工作字幕，同一视频可以用于多个工程。
- 参考 [MOSS-Transcribe-Diarize 字幕 Web UI](https://github.com/OpenMOSS/MOSS-Transcribe-Diarize#subtitle-web-app) 的字幕工作流，采用用户描述的剪映式工作区及时间轴操作。
- 词义见 [GLOSSARY.md](../../GLOSSARY.md)。编辑实体与时间基准见 [ADR-0001](../adr/0001-webui-subtitle-entry-editing.md)，保存语义见 [ADR-0002](../adr/0002-webui-project-persistence.md)。

## 2. 界面布局

深色中文界面，上方三个面板及上下分区可拖动调整尺寸。

```text
┌ 菜单：文件 · 编辑 · 视图 · 帮助 ──────────────────────┐
├ 项目操作栏：工程名 · 保存状态 · 导入 · 保存 · 导出 ────┤
│ 工程资源       │       视频预览       │ 字幕 / 说话人 │
│ 视频、字幕来源 │       播放控制       │ 列表与编辑区  │
├ 时间轴工具：撤销 · 重做 · 选择 · 拆分 · 合并 · 吸附 · 缩放 ┤
│ 视频轨（锁定；缩略图与音频波形）                      │
│ 字幕总览轨                                           │
│ 说话人 A                                             │
│ 说话人 B                                             │
│ ……                                                   │
│ 未标注 ?                                             │
│ 非对白 NONSPEECH                                      │
└──────────────────────────────────────────────────────┘
```

- **撤销、重做按钮位于时间轴工具栏**，这是用户明确修正的位置。
- 左上角显示当前工程资源：源视频、字幕来源、工作字幕、预览副本、导出文件；支持导入、素材重新定位及打开导出位置。菜单提供工程列表与切换。
- 右上角“字幕”页签包含按时间排列的列表、搜索和按说话人筛选，以及选中条目的正文、起止时间、归属编辑；多选时显示共同属性与批量操作。
- 右上角“说话人”页签管理名称、颜色、排序及合并。列表、字幕块和对应说话人轨使用一致颜色。

## 3. 时间轴与说话人

- 视频轨始终锁定，所有时间位于原片时间轴上。
- 字幕总览轨与说话人轨是同一条字幕的两种视图。任一处编辑都同步；重复显示不产生额外字幕。
- 不同说话人及同一说话人的时间重叠均合法。同轨重叠采用轨内错层显示，保证各条可选。
- 编辑选中条目不自动推移、裁剪或删除其他条目。
- 视频轨内显示缩略图和音频波形。时间轴支持横向缩放、横向滚动、说话人轨纵向滚动，以及可开关的播放头/字幕边界吸附。
- 时间字段按毫秒编辑，时间轴范围覆盖整部影片。

### 说话人管理

- 开放名单：按导入标签建轨，可新增、重命名、合并、改色及排序。角色资料可提供名称候选。
- 普通轨道初始按首次出现顺序排列，可拖动重排；未标注 `?` 和非对白 `NONSPEECH` 固定在底部。
- 无标签的字幕进入 `?`；已有 `Iroha&Kaguya` 等组合标签按一个完整标签保留。其他导入名称保留其原意。
- 删除有字幕的普通说话人轨时，将其字幕转入 `?`，作为一次可撤销操作。
- 重命名与已有名称冲突时，通过明确的“合并说话人”操作处理。
- 当前轨道顺序决定上下换轨目标。视频轨和字幕总览轨不是说话人目标。

## 4. 字幕编辑语义

| 操作 | 已确认行为 |
| --- | --- |
| 修改 | 可改正文、说话人、开始时间、结束时间 |
| 新增 | 在播放头处创建默认 2 秒的条目，临近片尾时缩短；采用当前明确选中的说话人，否则归到 `?`；填入正文后提交 |
| 删除 | 删除选中字幕，可撤销 |
| 横向拖动 | 改变选中字幕的时间，多选保持相对时间 |
| 拖动边缘 | 调整起止时间，保持有效时长 |
| 纵向拖动 | 改变说话人归属，时间保持不变 |
| 斜向拖动 | 同时修改时间和归属，整次拖动作为一个编辑操作 |
| 拖向总览 | 总览仍是同一数据的视图，不能借此清除原归属 |
| 拆分 | 播放头必须在单条选中字幕内部；切开时间，**两段先复制原全文**并沿用说话人，再分别编辑 |
| 合并 | 合并时间排序中连续选中的条目；取最早开始、最晚结束，正文按顺序换行；相同说话人直接合并，跨说话人须指定结果标签；结果覆盖中间空隙 |
| 替换字幕 | 整体替换工作字幕，作为一次可撤销操作；也可用同一视频另建工程 |

### 多选

- 支持 Ctrl 点选、Shift 连续选择与时间轴框选。
- 多选可批量改说话人、整体移动时间、删除或合并；拆分仅适用于单条。
- 多选按 ↑/↓ 时，各条按轨道顺序整体偏移一行。例如 A、B 各选一条，向下后分别归到 B、C。
- 任何一个选中条目将越过说话人轨边界时，整次换轨不执行；不首尾循环。
- 将多选项全部改为同一个人时，使用右侧批量归属选择。

### 有效状态

- 正文非空，时间满足 `0 ≤ start < end ≤ 视频时长`。
- 拖动到时间边界时停止；多选整体保持相对时间。
- 导入遇到非法时间、空正文等情况，报告具体条目与原因，修正文件后重新导入，不静默丢弃或改写。
- 重叠字幕是合法状态。

## 5. 播放、选中与键盘

- 普通单击字幕块或列表项：选中、暂停并定位到起点。
- 双击：从该条起点播放到终点；另有当前字幕循环试听。
- Ctrl/Shift 点选与框选只改变选择，不跳转播放头。
- 拖动播放头即时更新画面；播放经过的条目高亮与编辑选择分开，不抢走正在编辑的选择。
- 播放器叠加当前工作字幕，可开关字幕及说话人名称；同一时刻多条字幕错位并列显示。
- 支持播放/暂停、时间跳转、0.5～2 倍速及当前字幕循环试听。

| 按键 | 时间轴/非文本编辑状态 |
| --- | --- |
| ↑ / ↓ | 将选中字幕归属整体移动到上一/下一说话人轨 |
| ← / → | 选择上一/下一条字幕 |
| 空格 | 播放/暂停 |
| Delete | 删除选中字幕 |
| Ctrl+B | 在播放头拆分单条选中字幕 |
| Ctrl+M | 合并符合条件的选中字幕 |
| Ctrl+S | 立即保存工程 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Esc | 取消当前手势或清除选择 |

文字输入框内，方向键、空格、删除与撤销优先处理文本输入；结束输入后整次文字修改作为工程编辑历史中的一个操作。

### 编辑历史

- 正文、时间、归属及说话人轨配置修改均可撤销/重做。
- 一次拖动、一次批量操作、一次连续文字编辑各算一步。
- 播放、滚动、缩放不进入编辑历史。
- 保存不清空历史；重开工程后以保存结果为起点建立新历史。

## 6. 导入、保存与导出

### 导入

- SRT：导入预览明确选择“普通 SRT / 本项目 `[Speaker]` 格式 / MOSS 冒号格式”。普通模式保留正文并归到 `?`；项目模式解析说话人前缀与已知元标签；MOSS 模式解析冒号前的说话人名称。
- 本项目 normalized JSONL：保留说话人、`tags` 和 `source_entries` 等已有信息。
- MOSS JSON：支持其导出的顶层字幕数组，每项包含 `id/start/end/speaker/text`，时间单位为秒。
- MOSS 下载 JSON 不带其 UI 的人物名称映射，导入后按文件中的 `S00` 等 ID 建轨，再通过 UI 重命名。
- 当前导入和导出格式的事实依据：`sub/_srt_io.py`，以及本地 MOSS 参考检出的 `moss_transcribe_diarize/subtitle/models.py`、`export.py`。

### 工程保存

- 默认目录：`webui/workspace/<工程ID>/`；独立工程文件记录当前工作字幕、说话人配置和媒体路径。
- 原视频按路径引用，预览缓存放工程目录；支持工程另存为。
- 编辑完成后短暂延迟自动保存，显示保存中、已保存或保存失败；Ctrl+S 立即保存。
- 导出使用当前已提交的编辑结果。
- 原片移动后通过“重新定位”找回同一媒体。真正换用另一份视频则新建工程，可带入当前字幕副本。

### 导出

| 格式 | 内容 |
| --- | --- |
| 说话人 SRT（默认） | 干净的 `[Speaker] text` |
| 普通 SRT | 仅字幕正文 |
| 本项目 JSONL | 字幕、说话人、已有标签及来源索引 |
| MOSS JSON | `id/start/end/speaker/text` 数组 |

- SRT 按时间排序并重新编号，已有 tags 通过明确的导出选项保留。
- 工程和适用的结构化格式保存已有来源信息；SRT 本身不承载来源索引。
- `source_entries` 是原来源索引，不能用重新编号后的字幕序号替代，也不能将 MOSS 的段 ID 当作此索引。
- 保存与导出遵循不同职责，导入文件继续作为来源。

## 7. 媒体兼容与交付形态

- 浏览器不能直接播放时，提供“生成预览副本”，显示进度并缓存结果；副本保持原片时间基准。
- 缩略图、波形和预览副本生成均有进度反馈与缓存。
- 实现代码集中在根目录 `webui/`，采用 React + TypeScript 前端与轻量 Python/FastAPI 本地服务。
- 提供依赖安装说明及 Windows 一键启动脚本；完成安装后，启动本机服务并在桌面浏览器使用。
- 主要体验目标是整部电影、数千条字幕的连续校对。

## 8. 后续实现时的事实约束

- 当前主项目没有现成的产品 Web 服务或前端；本地 MOSS 是独立参考检出，其服务与数据结构不能视为主项目已具备的接口。
- 现有 `sub/_srt_io.py` 的 SRT parser 要求说话人前缀，普通 SRT 需要适配。其现有 parser 也不等于完整编辑校验器。
- 当前字幕序号不是跨拆分、合并和重排的稳定身份；编辑器需要保持条目身份与导出序号之间的区别。
- 改动字幕结构、时间和正文后，旧的场景划分与模型结果可能已不对应新的工作字幕。首版交付物是独立工程及显式导出结果。
