Subtitle-driven multimodal pipeline

从字幕间隙，
到最终说话人

这是一个缩小后的完整演示：DeepSeek 只判断语义边界，Python 保证 scene 完整覆盖，Gemini 再结合 scene、前文字幕和视频音频，为每条字幕选择一个 speaker。

两个模型，职责不重叠。 DeepSeek 不看视频、不改 speaker；Gemini 不决定生产 scene 边界。稳定的 idx 将两个阶段连接起来。

1. Normalized SRT 提供稳定 entry

演示使用 idx 1-12。每个相邻 entry 后面都是一个潜在边界；实际生产会先排除 NONSPEECH 和含 ♪ 的条目。

Python 读取与筛选
目标 entry圆点表示相邻字幕间隙，目前还不是 scene 边界
entry = { idx, start, end, speaker, tags, text }

稳定标识：idx
DeepSeek 阶段：用 idx 表达 after_idx 切点
Gemini 阶段：用 idx 返回 speaker
写回阶段：用 idx 找回原 start/end/text

2. 每个候选边界只归一个 DeepSeek 请求负责

调小演示中的请求窗口和上下文，观察相邻请求虽然会看到重叠字幕，但不会共同决定同一个 after_idx。

DeepSeek 文本判断
演示自动选择语义切点 after_idx=4、8。真实 DeepSeek 根据地点、事件、叙事结构和对话承接决定，不能因为字幕多或 speaker 轮换就切。

3. Refine 可以删除旧切点，也可以添加新切点

第一遍可能把连续问答切开，或遗漏一个独立事件。Refine 只复核可疑 scene 及邻居，并返回区域内应该保留的全部最终 cuts。

DeepSeek 不返回完整 scene 列表。Python 按 entry 顺序切开，保证模型无法通过漏写范围让字幕消失。
