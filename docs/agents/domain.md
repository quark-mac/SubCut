# Domain Docs

本仓库采用单领域布局：根目录 `GLOSSARY.md` 与 `docs/adr/`。

## 读取规则

- 探索领域行为或开展设计前，读取 `GLOSSARY.md`。
- 读取与本次任务相关的 ADR；WebUI 工作另读 `docs/design/webui.md`。
- 将来若出现 `GLOSSARY-MAP.md`，按其指向读取相关领域文档。
- 文档缺失时继续工作，待术语或重要决定明确后按需创建。

## 使用规则

- 规格、任务、代码命名和测试描述采用术语表中的词义。
- 发现术语缺口时，在领域建模过程中澄清并记录。
- 与已有 ADR 冲突的方案须明确指出冲突和重新讨论的理由。
- 术语表只记录领域概念；重要取舍写入 ADR，功能要求写入设计或规格。
- 保留现有文档布局，项目行为契约以 `AGENTS.md`、
  `docs/CURRENT.md` 及相关设计文档为准。
