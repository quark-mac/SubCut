**没有取得足以确认 CapCut / 剪映桌面端“轨道底边拖动”或“全局高度滑杆”的一手操作证据。** 本次也未核实轨高最小值/最大值、调节是否影响全部轨道、是否按媒体类型分别调节，以及播放头上方是否有随拖动出现的缩略图浮层。不能将这些细节写成“与剪映相同”或“剪映就是这样操作”。

能够定位的一手帮助文字明确提到：在桌面端添加效果后，移动播放头预览效果。它支持“播放头定位 → 画面预览”的基本关系，**不证明浮层的位置、触发方式或尺寸**。[S1]

本项目可直接采用：**每条媒体轨底边独立拖高；缩略图随视频轨高度等比重排；拖动播放头时在其上方显示帧图与时间；音频波形独立开关、默认隐藏，显示后拥有独立且更高的初始高度。** 这些满足用户表达的需求，但应作为本项目的明确交互契约，而不是未经核实的 CapCut 复刻。

## 推荐实现契约（本项目建议，非 CapCut 已验证事实）

### 1. 轨高：底边独立拖动，明确命中区域

1. 在视频轨和可见的波形轨底边放置约 **6–8 CSS px** 的拖动命中区；鼠标进入显示 `ns-resize`，边界高亮，提示“拖动调整视频轨高度”或“拖动调整波形轨高度”。
2. 主按钮按下记录 `startY` 与 `startHeight`；拖动使用 `clamp(startHeight + deltaY, min, max)`，实时改变该轨高度。使用 pointer capture，鼠标离开轨道后仍能完成拖动。
3. 轨高拖动事件应优先于播放头定位事件：操作轨道底边时仅改高度，避免同时 seek、改变字幕选区或拖动片段。水平时间缩放与轨高为不同状态。
4. 各轨独立保存高度。若日后增加“所有轨道高度”滑杆，必须明确标成“全部媒体轨道”，由用户显式操作；不让单轨拖动隐式修改其他轨道。
5. 可给轨头提供同状态的“紧凑 / 标准 / 大”预设与重置入口，帮助发现能力。可聚焦的高度控件支持方向键调节，避免操作只依赖细边界。

建议初值（**均为本项目可调参数，不是 CapCut 数值**）：

| 轨道 | 默认可见 | 初始高度 | 最小高度 | 最大高度 |
| --- | --- | ---: | ---: | ---: |
| 视频缩略图轨 | 是 | 96 px | 48 px | 192 px |
| 独立音频波形轨 | 否 | 144 px | 72 px | 256 px |

最大高度还应受实际工作区可用高度约束；轨道变高后允许轨区纵向滚动，不挤掉时间尺和基本播放控件。

### 2. 视频轨：缩略图随高度适配

- 视频轨高变化后，缩略图使用可用内容高度，按源视频宽高比计算宽度，保持人物/画面比例；必要时以 `contain` 留边显示完整帧。
- 列宽变化时重新计算可见缩略图数与采样点。每列采样时间来自它在时间线上的位置，不能仅放大原来固定数量的图片后留下空白。
- 轨高只改变展示密度；时间尺、时间→像素映射、字幕位置与播放头时间保持一致。
- 预览与轨道缩略图可共享已有缓存；拖高过程优先重排已缓存图像，再按需补充，避免每个 pointer move 都发起解码请求。

### 3. 拖动预览：播放头上方显示帧图和时间

1. 从播放头手柄或时间尺开始定位拖动时，显示预览浮层；它显示当前目标时间的图像与时间码，松手/取消/失去拖动状态时隐藏。普通悬停是否预览可留作后续独立功能。
2. 水平位置跟随播放头，并 clamp 到可视时间线边界内；垂直位置优先在时间尺/播放头上方，空间不足时调整到可见区域。使用不受轨道 `overflow` 裁切的浮层容器。
3. 例如使用 **192 × 108 px** 图像区域加时间码行，源图等比显示；尺寸为本项目建议。浮层 `pointer-events: none`，不遮挡鼠标操作目标。
4. 拖动取时必须同时处理时间线左边界、轨头宽度、水平滚动和时间缩放。目标时间限定在媒体有效区间。
5. 播放头位置与时间码可逐动画帧更新；帧读取采用合并请求/只保留最新目标，防止较早的异步结果覆盖较新的预览。只有低频缩略图缓存时，应把近似图像与精确 seek 结果区分，避免把秒级采样宣称为逐帧预览。
6. 松手后将最终目标时间提交给主播放器。是否拖动期间也同步主播放器应与现有 seek 行为保持一致；浮层可以优先使用缓存，避免高频重解码。

### 4. 音频波形：独立、默认隐藏、按需加载

- 提供清晰的“显示音频波形”开关，初始关闭；关闭时波形轨不占纵向空间，音频播放不受影响。
- 开启后出现独立音频轨，使用比默认视频轨更高的初始高度，自己的底边可以继续拖高；关闭再开启保留用户设定的波形轨高度。
- 波形的时间坐标与视频/字幕共用。轨高决定画布高度；若另外提供“波形显示增益”，应与音量控制区分，避免视觉放大改变声音。
- 初次开启才按需取得波形数据，显示加载/空音轨状态。默认隐藏状态不应为尚未使用的波形产生昂贵的构建请求。

## 建议验收点

- 视频轨底边上下拖动只改变视频轨高；音频高度、当前时间、时间缩放保持原值。
- 视频在最小/最大轨高都有连续且比例正确的缩略图；改变高度不改变字幕与画面的时间对齐。
- 在水平滚动、不同缩放和时间线左右边缘拖动播放头，预览时间/图像相符且浮层完整可见；松手后隐藏。
- 快速往返拖动时，旧的异步帧结果不会覆盖较新目标；有缓存缺帧时不显示伪造的精确帧。
- 首次进入波形隐藏；显示后可独立调高；再次关闭不留空白轨，也不禁用音频播放。
