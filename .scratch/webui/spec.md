# WebUI 字幕与说话人编辑器

Status: ready-for-agent
Date: 2026-10-15
Feature: webui

## Problem Statement

用户需要对长视频的字幕及说话人标注进行人工校对。当前项目已经具备字幕处理、模型标注和导出工具，但缺少一个将视频播放、原片时间轴、字幕文字和说话人归属放在一起操作的界面。

仅查看或编辑字幕文件不便于逐句试听、比较重叠字幕、调整时间和批量纠正说话人。用户希望使用接近剪映的操作方式，通过点击、拖动、键盘换轨和撤销重做完成校对，并可靠地保存编辑进度、导出可供现有工具继续使用的字幕。

## Solution

提供本机单人使用的中文 WebUI，采用深色、可调整面板尺寸的剪映式工作区，参考 MOSS 字幕 Web UI 的导入、校对和导出流程。每个编辑工程包含一份视频、一份工作字幕及说话人设置。

顶部是菜单和项目操作栏；上部从左到右依次为工程资源、视频预览、字幕与说话人编辑器；底部依次为锁定视频轨、字幕总览轨、各说话人轨。撤销与重做按钮位于时间轴工具栏。

字幕总览轨与说话人轨展示同一批字幕条目。修改文字、时间或归属会同步反映到列表、轨道和播放器叠加字幕中。支持完整字幕编辑、多选、上下键换轨、波形、缩略图、吸附、循环试听和当前打开期间的编辑历史。

工程独立保存并自动落盘，视频按原路径引用；浏览器不能直接播放时生成保持原片时间基准的预览副本。支持 SRT、本项目 normalized JSONL、MOSS JSON 导入，并导出带说话人的 SRT、普通 SRT、本项目 JSONL 和 MOSS JSON。

## Implementation Decisions

### 架构与职责

- 首版面向 Windows 本机单人、桌面浏览器，前端采用 React + TypeScript，本地服务采用 Python/FastAPI；安装后由启动脚本启动本机服务并打开浏览器。
- 新增独立 WebUI 子系统，包含编辑工作区、工程持久化、字幕格式适配、媒体服务四个职责。编辑工作区维护当前编辑状态和会话内历史；服务负责文件访问、校验、持久化、导出与媒体任务。
- 复用现有字幕格式契约；现有要求说话人前缀的 SRT 解析器不能直接充当普通 SRT 导入器。格式适配放在新子系统边界内。
- MOSS 是工作流与格式参考，其独立服务、任务存储和模型运行时不是本功能的运行依赖。
- 本功能保持现有生产处理流程与默认参数；字幕导出是与已有工具交换结果的接口。

### 工程与条目数据契约

- 工程有稳定身份、名称、格式版本、原媒体引用、字幕来源记录、工作字幕及说话人配置。格式版本不受支持时明确报告，不按未知结构覆盖保存。
- 一份工程只关联一份原视频和一份工作字幕；同一原视频可被多份工程引用。
- 每条字幕具有独立稳定身份、起止时间、正文、说话人引用、已有元标签和来源信息。条目身份与导出序号分离；重排或重命名说话人不改变条目身份。
- 说话人具有稳定身份、标签名称、颜色及轨道顺序。特殊标签使用固定语义；普通名称不采用封闭枚举。
- 工程内部使用整数毫秒；秒制 JSON 输入在边界统一换算，导出按相应格式表示。正文保留真实换行。
- 有效条目须满足正文非空、时间有限且 0 ≤ start < end ≤ 媒体时长；重叠合法。换算后时长为零的输入也须报告为错误。
- 导入来源序号和当前导出序号分别记录。原 ASS 来源索引不能由当前序号推导，MOSS 段 ID 也不能充当原 ASS 来源索引。
- 拆分后的两条字幕继承原有来源与元标签；合并保留参与条目的来源关联和元标签。新增字幕没有虚构的源条目。撤销恢复操作前的身份、来源和内容。
- 列表与输出采用确定性时间排序：先开始、再结束，相同时间保持稳定的条目顺序；导出序号从 1 连续生成。

### 工作区与播放

- 顶层菜单包含文件、编辑、视图和帮助；下一层项目操作栏显示工程名、保存状态、导入、保存与导出。
- 上部依次为工程资源、播放器、右侧编辑器。面板宽度及上下分区高度可调；右侧用字幕与说话人页签切换。
- 资源区呈现源视频、字幕来源、工作字幕、预览副本及导出文件；菜单提供工程列表与切换。
- 字幕页签提供搜索、说话人筛选、条目列表及正文/时间/归属编辑。多选呈现共同属性，混合属性明确显示为不同值；提交批量值才修改各条。
- 时间轴工具栏包含撤销、重做、选择、拆分、合并、吸附及缩放。轨道顺序固定为锁定视频、字幕总览、普通说话人、未标注、非对白。
- 总览与说话人轨引用同一批条目。同轨重叠采用轨内错层以便分别选择；播放叠加同时出现的字幕也须错位显示。
- 单击字幕块或列表项选中、暂停并定位到起点；双击播放该条并在终点停止。Ctrl/Shift 点选与框选只修改选择。
- 播放高亮与编辑选择分离，播放不抢走编辑对象。拖动播放头更新画面；支持时间跳转、0.5～2 倍速及当前字幕循环试听。
- 播放器使用当前工作字幕，允许开关字幕及说话人名称。时间轴内的波形和缩略图对应原片时间，支持横向缩放/滚动及说话人轨纵向滚动。
- 吸附可开关，目标为播放头和字幕边界；关闭后允许按毫秒微调。视频轨不支持移动、裁剪或解锁。

### 说话人管理

- 普通轨道按首次出现顺序初始化，可拖动排序；`?` 和 `NONSPEECH` 为底部固定特殊轨道，分别显示未标注、非对白。
- 无说话人标签的普通字幕归入 `?`。组合标签如 `Iroha&Kaguya` 作为完整标签建轨；其余名称保留原意。
- 支持新增、重命名、改色、重排及明确合并普通说话人。名称冲突不隐式覆盖，应选择合并操作。
- 删除有字幕的普通轨道将相关字幕转入未标注，整体可撤销；特殊轨道身份及语义保留。
- 轨道、字幕块和列表的说话人颜色一致。可利用角色资料提供候选名称，但不限制开放名单。

### 编辑操作与历史

- 新增字幕位于播放头，默认长 2 秒，接近片尾时缩短；使用当前明确选中的说话人轨，否则归入未标注。填写正文后提交，片尾不能创建零时长字幕。
- 横向拖动改变时间，边缘拖动改变时长，纵向拖动改变归属；斜向拖动可同时修改时间与归属，作为一个操作。拖向总览不清除归属。
- 多选支持 Ctrl 点选、Shift 连续选择与框选，可批量改归属、移动时间或删除。整体移动保持相对时间并在媒体边界停止。
- 上下换轨按当前轨道顺序整体偏移一行。若任一选中条目越界，整次不执行，不首尾循环；视频轨和总览轨不是归属目标。
- 多选归到同一人使用右侧批量选择。修改选中条目不推移、裁剪或删除未选条目。
- 拆分仅作用于单条字幕，播放头必须严格位于内部；生成时间相邻的两条，两段先复制全文并沿用原说话人。
- 合并仅接受按时间排序连续选中的条目，使用最早开始与最晚结束，正文按顺序换行拼接。相同说话人直接合并；跨说话人须明确选择结果标签。结果覆盖原条目间空隙。
- 整体替换字幕作为一次可撤销操作，相关来源及说话人引用同步更新；撤销恢复完整替换前状态。也可用同一视频另建工程。
- 正文、时间、归属和说话人配置均进入会话内编辑历史；一次拖动、批量操作或连续文字编辑各算一步。播放、滚动、缩放不进入历史。
- 保存不清空历史；重新打开工程建立新历史。撤销后执行新编辑时，旧的重做分支失效；被取消或无效的操作不制造历史步骤。

### 键盘与输入焦点

| 按键 | 非文本编辑状态下的行为 |
| --- | --- |
| ↑ / ↓ | 选中字幕整体换到上一/下一说话人轨 |
| ← / → | 选择上一/下一条字幕 |
| 空格 | 播放/暂停 |
| Delete | 删除选中字幕 |
| Ctrl+B | 在播放头拆分单条选中字幕 |
| Ctrl+M | 合并符合条件的选中字幕 |
| Ctrl+S | 立即保存 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销/重做 |
| Esc | 取消当前手势或清除选择 |

文字输入框内，方向键、空格、删除及撤销优先处理文字。输入结束后，完整文字修改作为一个工程编辑操作。保存或导出先提交有效输入；存在无效输入时定位到相应字段并说明原因，不用旧值冒充当前编辑结果。

### 导入与导出契约

- SRT 导入提供普通、本项目方括号说话人、MOSS 冒号说话人三种模式，并展示解析预览。普通模式完整保留正文并归入未标注；项目模式解析说话人及已知元标签；MOSS 模式只按所选前缀约定解析。不得将所有方括号或冒号文本自动猜成人物名。
- 本项目 JSONL 接受字幕序号、秒制起止时间、说话人、正文、元标签和源条目索引；已有来源信息进入工程，缺少来源时保持为空。
- MOSS JSON 接受顶层数组，条目含 id、start、end、speaker、text。下载文件没有人物显示名映射，按文件中的说话人 ID 建轨；导入 ID 作为来源信息保留，与工程条目身份分开。
- 导入先完整解析和验证，再一次提交；错误返回条目位置、字段和原因。失败不部分替换现有工作字幕，不静默修正非法时间或丢弃条目。
- 默认导出干净的说话人 SRT，另提供普通 SRT、本项目 JSONL、MOSS JSON。导出基于操作触发时的当前已提交状态，后续编辑不混入同一次输出。
- 说话人 SRT 写出当前标签与正文；普通 SRT 只写正文。SRT 排序并连续编号，保留已有元标签须显式启用。
- JSONL 输出与现有项目字段及秒制时间兼容，并保存已有元标签、原来源索引；MOSS JSON 输出其五字段数组并保证段 ID 唯一、使用当前说话人标签。
- SRT 或 MOSS JSON 缺少表达某些工程信息的字段时，不宣称它们能完整往返工程状态。工程文件是继续编辑的完整保存对象。

### 持久化与公共服务接口

- 工程默认集中存放，媒体按原路径引用；预览及可再生缓存归属工程。另存为产生独立工程身份、复制当前编辑状态并继续引用原片。
- 编辑提交后短暂延迟自动保存，Ctrl+S 立即保存。显示保存中、已保存或保存失败；已保存只对应服务确认落盘的版本。
- 保存请求带工程修订信息，防止较早请求覆盖较新编辑；失败保留当前编辑状态并允许重试。写入采用原子替换，避免失败留下半份工程文件。
- 公共 HTTP 边界覆盖工程创建、列出、读取、保存、另存为；字幕导入预览、应用和导出；媒体读取、重新定位、生成任务及状态查询。响应明确提供资源身份、修订或任务状态。
- 字段错误具有可定位信息；文件缺失、版本冲突、保存失败和媒体失败分别给出可理解原因。导出返回实际生成的文件引用，资源区可打开其位置。
- 视频读取支持浏览器按范围请求以定位播放。重新定位用于同一原片；另一视频应新建工程，可带入当前字幕副本。
- 源素材与导入字幕保留为来源；保存工程不会覆盖它们。

### 媒体处理与交付

- 视频是否可播放由实际容器、编码与浏览器能力决定，不仅检查扩展名。不兼容时提供生成预览副本操作，采用浏览器支持的编码并保持原片音画及字幕时间基准。
- 预览副本不能使用去掉空隙的推理用紧凑视频；播放定位、波形、缩略图和字幕均引用原片时间。
- 预览转换、波形及缩略图生成通过后台任务执行，公开等待、运行、成功、失败状态及进度。失败结果不作为有效缓存。
- 缓存有效性关联源媒体身份和生成参数；重开工程可复用有效缓存，媒体变化或参数变化后不能错误复用旧结果。
- 提供依赖安装说明、所需媒体工具检查和 Windows 启动入口；开发及测试的启动方式需可重复执行。
- 编辑工作区按可见范围渲染长列表及时间轴内容，避免每次播放位置更新都重建整片所有字幕。具体渲染实现可由实现任务选择，验收以用户可观察行为为准。

## Testing Decisions

### 已确认的测试边界

用户已确认：主要从真实浏览器验证完整操作流程；公共 HTTP 接口补充验证格式、错误处理、持久化与媒体任务；至少一次真实 FFmpeg 预览生成及浏览器播放检查，并进行整片规模检查。

- 好的测试通过用户操作、公共请求与实际输出文件证明行为。避免依赖组件内部状态、私有函数或命令历史的内部表示。
- 浏览器检查覆盖工作区、时间轴编辑、输入焦点、播放联动、保存重开和导出；真实前后端参与主要闭环。
- HTTP 测试覆盖工程持久化、格式适配和媒体服务边界，使用临时工作区与小型自建素材。
- 仓库已有从导出 CLI 公共入口运行、在临时目录检查产物的回归测试；可复用其外部行为验证思路。当前尚无 WebUI 浏览器或 HTTP 测试基础设施，首个相关实现任务须建立并记录执行命令。
- 可对外部失败条件注入故障，但不能以所有媒体调用均被替代的测试代替真实媒体验收。

### 验收场景

1. **编辑闭环**：导入小型视频及字幕，修改正文、时间和归属，保存、关闭、重开并导出；实际文件与最后提交结果一致。
2. **共享条目**：从总览轨或说话人轨编辑同一条字幕，列表、轨道、预览同步；多选两种视图中的同一条目不会造成重复修改。
3. **换轨与重叠**：验证单选、多选、轨道排序后换轨、底部特殊轨道和越界不执行；同轨重叠仍可分别选中，其他字幕不被推移。
4. **结构编辑**：拆分复制全文且边界准确；合并拼接文字、覆盖间隙并要求跨人选择归属；新增、删除、整体替换及来源关联可正确撤销。
5. **历史**：一次拖动和批量操作各撤销一步；重命名、合并、删除说话人可恢复；保存不清空历史，重开建立新历史，撤销后新编辑清除旧重做分支。
6. **焦点与播放**：文本输入不误触换轨、播放或删除；普通点击定位，多选不定位，双击到终点停止，循环和变速有效；播放不抢编辑选择。
7. **格式**：覆盖三种 SRT 解释模式、JSONL 和 MOSS JSON；测试多行正文、特殊标签、组合标签、相同时间与元标签导出开关；验证来源索引不被重编号改写。
8. **错误与恢复**：非法时间、空正文和畸形文件提供条目错误且不部分导入；保存失败不显示已保存，重试可恢复；并发保存响应顺序变化不覆盖较新状态。
9. **媒体**：验证原片定位与范围读取；使用真实不兼容素材生成可播放副本，对照多个位置检查画面、声音和字幕时间一致；检查任务进度、失败状态及缓存复用。
10. **规模与交付**：使用整片时长、数千条字幕与多个说话人的工程，实际完成加载、搜索、缩放、滚动、播放中编辑、保存重开。记录素材规模、浏览器、硬件及观察到的延迟；按安装说明验证 Windows 启动。当前尚未承诺具体毫秒级性能指标。

完成条件：上述场景通过，所选测试入口及命令可重复运行，失败场景有明确结果；记录实际验证证据。Python 改动遵循仓库编译检查要求，前端完成类型检查及构建。字幕模型准确率不属于本功能的验收指标。

## Out of Scope

- 在 UI 中运行归一化、语义场景生成、Gemini 标注、声学聚类或 Gold 评估。
- 视频剪辑、视频轨解锁、素材重排、多视频时间线和同工程多份工作字幕。
- 原始 ASS 导入、字幕烧录、角色媒体片段导出及完整磁盘文件管理器。
- 远程部署、多用户协作、账号权限和跨会话持久化撤销栈。
- 自动猜测拆分点对应文字、自动推移重叠字幕，或将说话人轨作为独立时间片段维护。
- 修改既有生产默认值、重写源字幕或 Gold、自动复用编辑前的场景和模型结果。
