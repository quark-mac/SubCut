# 10: 工程切换、另存为与素材重新定位

Status: ready-for-agent
Blocked by: 02
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户从菜单切换工程，另存当前结果，查看资源与导出位置；原视频移动后可找回同一原片，也可用另一视频和当前字幕副本建立新工程。

## 上下文与修改范围

- 对应用户故事 3–9；依赖 02 的可靠保存与修订语义。
- 修改 WebUI 工程菜单、资源区、工程复制/读取/媒体重新定位接口及测试。采用当前工程 schema 和已支持格式即可验收。
- 单工程单视频单工作字幕；工程复制与字幕导出不同，视频保持路径引用。

## Acceptance criteria

- [ ] 工程列表可显示并打开已有工程，同一视频可用于多个工程；切换后名称、字幕、说话人设置和保存状态属于所选工程。
- [ ] 切换及另存为先处理当前有效编辑；保存失败时保留待保存状态并提供可理解的恢复方式，不以失败结果显示已保存。
- [ ] 另存为生成独立工程身份，复制当前字幕、人物配置与有效来源关系，引用原视频；修改副本不改原工程。
- [ ] 资源区展示当前可用的源视频、字幕来源、工作字幕、媒体派生产物及导出文件；可从 UI 打开实际导出位置。
- [ ] 原视频移动或缺失时，工程仍保留完整编辑数据，并可选择同一原片的新路径；恢复后定位、时长及字幕基准一致。
- [ ] 重新定位与换视频分开；换用另一原片通过新建工程，可带入当前字幕副本并按新视频时长验证，失败不改变原工程。
- [ ] 媒体身份、路径与已有缓存引用保持一致，可供后续媒体任务判断缓存有效性；不会因失联素材清空工作字幕。
- [ ] 列表、读取、另存为与重新定位的公开服务响应包含可识别工程/资源及错误；未知格式版本明确报告。

## Verification

1. 浏览器建立两个使用同一视频的工程，编辑、切换、另存为并重开；用公共读取结果验证身份独立及来源完整。
2. 移动测试原片后重新定位，验证播放位置和字幕；再以另一较短视频创建带字幕副本工程，检查越界错误及原工程保留。
3. 验证保存失败时切换行为和资源区打开真实导出位置；运行公共 HTTP/浏览器回归及相应构建检查，记录证据。
