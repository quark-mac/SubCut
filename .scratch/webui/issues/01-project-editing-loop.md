# 01: 最小工程校对闭环

Status: ready-for-agent
Blocked by: none
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户启动本地 WebUI，选择一份可直接播放的视频和普通 SRT，创建工程、播放定位、修改字幕正文、手动保存，重开工程后导出普通 SRT。首次交付即是一条真实可操作的校对流程。

## 上下文与修改范围

- 对应用户故事 1–4、6、13、32、56、58 的基础闭环。
- 在 WebUI 子系统建立 React + TypeScript 工作区、Python/FastAPI 本地服务、工程存储与测试入口。沿用统一字幕条目、原片时间轴和独立工程保存的决策。
- 使用临时工程目录和自建小型素材验证。实现范围为该子系统、配套测试与开发启动说明；现有生产工具通过已有格式契约衔接。

## Acceptance criteria

- [ ] 记录可重复执行的依赖安装、服务启动、浏览器测试、HTTP 测试、前端类型检查与构建命令；浏览器实际连接本地服务。
- [ ] 基本工作区呈现深色中文菜单、项目操作栏、左侧资源、中部播放器、右侧字幕列表/正文编辑区及底部时间轴区域。
- [ ] 从用户选定的本地视频路径创建单视频单工作字幕工程；原片按路径引用，可播放并通过浏览器范围请求定位。
- [ ] 普通 SRT 导入提供预览，完整保留正文与换行，归入未标注 `?`；错误提供条目、字段及原因，不部分创建工程。
- [ ] 工程有格式版本、稳定工程/字幕/说话人身份、原媒体引用、字幕来源及当前工作字幕；内部时间为整数毫秒，来源序号不作为条目身份。
- [ ] 编辑正文经过非空校验；时间满足原片范围内正时长，合法重叠保留。手动保存与重开恢复修改，菜单可列出并打开已建工程。
- [ ] 导出普通 SRT 使用当前已提交状态，按开始、结束和稳定次序排序，连续编号，多行正文保留；产物在资源区可见。
- [ ] 导入文件与原视频保持为来源；不支持的工程版本或缺失媒体明确报告，不以空内容覆盖原工程。
- [ ] 公共 HTTP 请求能验证工程创建、读取、保存、字幕导入和导出；错误具有用户可理解的信息。

## Verification

1. 用短视频、含换行与时间重叠的普通 SRT，从浏览器完成创建、播放定位、改正文、保存、重开、导出，并读取实际产物比对。
2. 通过 HTTP 验证非法时间、空正文、格式错误、未知工程版本和缺失媒体；确认失败不留下半个可打开的工程或部分字幕。
3. 执行本任务建立的自动化入口、前端类型检查/构建和仓库规定的 Python 编译检查。在 Comments 记录实际命令、结果与浏览器观察。
