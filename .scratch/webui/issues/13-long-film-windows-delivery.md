# 13: 长片体验与 Windows 交付验收

Status: ready-for-agent
Blocked by: 05, 08, 09, 12
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户按安装说明在 Windows 启动完整编辑器，对整片时长和数千条字幕连续校对，滚动、搜索、播放中编辑、保存和导出均保持可用，获得可重复运行的交付版本。

## 上下文与修改范围

- 对应用户故事 1、64，并验收规格所有功能组合后的闭环。
- 直接前置是人物管理、结构编辑、试听工作区和波形缩略图；这些依赖的传递闭包覆盖其余功能任务。
- 修改 WebUI 长列表/时间轴可见范围渲染、交互性能、启动与安装说明及集成测试。仅处理本功能的整合问题，按各前置任务既有接口保持行为兼容。

## Acceptance criteria

- [ ] 长列表和时间轴按可见范围工作，播放位置更新不会持续重建整片全部条目；滚动和缩放后选择、错层及手势命中保持准确。
- [ ] 用整片时长、数千条字幕和多个说话人的工程完成加载、搜索、横纵滚动、缩放、播放中编辑、撤销、保存重开与导出，不出现条目丢失或长时间失去交互。
- [ ] 记录素材规模、浏览器、硬件、冷/热缓存条件以及加载、编辑响应和保存的实际观察；发现明显阻塞时修复并重测相关场景，不以未经测量的性能数字宣称通过。
- [ ] 完整流程覆盖普通 SRT、带标签 SRT、JSONL、MOSS JSON，验证多轨编辑、人物管理、批量操作、结构编辑、来源保留、保存重开及四种导出。
- [ ] 完成真实不兼容视频的预览生成与播放，叠加字幕、波形、缩略图及定位一致，缓存复用和失败恢复可观察。
- [ ] 提供实际可用的 Windows 一键启动入口、依赖安装及媒体工具检查说明；安装后启动本机服务并打开浏览器，启动失败给出可理解原因。
- [ ] 工程与缓存的默认位置、导出方式、素材重新定位、快捷键及测试运行方式写入使用说明；所有按钮和菜单对应已交付行为。
- [ ] 运行规格列出的十组验收场景及已有公共测试入口，完成前端类型检查/构建、相关 Python 编译检查，并保存实际执行证据。

## Verification

1. 按安装说明在独立临时工作区运行 Windows 启动入口，使用自建短素材执行可重复的完整浏览器/HTTP/真实媒体闭环。
2. 使用可复现的长片规模字幕夹具及代表性媒体，记录规模与环境，实际进行持续滚动、缩放、播放中编辑、结构改动、人物操作和持久化检查。
3. 对照规格十组验收场景逐项记录结果；需要人工观察的播放和布局检查保留说明或截图，将命令、输出及修复后复验结果写入 Comments 或其引用的验证记录。
