# 04: 共享字幕多轨时间轴

Status: ready-for-agent
Blocked by: 02
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户在同一原片时间轴上看到锁定视频轨、全部字幕总览和按归属分组的说话人轨，点击字幕定位画面、拖动播放头预览，并通过上下键修正单条字幕的说话人。

## 上下文与修改范围

- 对应用户故事 18–22、25–26、30、36、46、50；依赖 02 的编辑及历史接口。
- 修改 WebUI 时间轴、选择/播放联动和相应测试。使用现有基础导入及公开编辑接口建立多说话人夹具，不要求扩展格式任务已完成。
- 总览和说话人轨是同一条目的两个视图，视频轨使用原片时间且始终锁定。

## Acceptance criteria

- [ ] 轨道自上而下为视频、字幕总览、普通说话人、未标注、非对白；普通轨初始按首次出现排序，列表和轨道人物颜色一致。
- [ ] 总览与说话人轨共享稳定条目身份；编辑或选中某条后，另一视图与右侧编辑器同步，保存后不产生重复字幕。
- [ ] 同轨和跨轨重叠均合法，同轨错层显示且每条可分别选中。
- [ ] 普通单击选中、暂停并定位字幕起点；播放高亮与编辑选择分离，播放不会抢走正在编辑的条目。
- [ ] 拖动播放头更新实际视频画面，时间刻度、字幕块与原片播放时间一致；视频轨不提供解锁、移动或裁剪操作。
- [ ] 支持横向缩放、横向滚动及说话人轨纵向滚动，时间范围覆盖原片；缩放不改变条目时间或历史。
- [ ] 单选 ↑/↓ 改到相邻说话人轨且时间不变；到边界时不执行，不循环，不把总览或视频作为归属。
- [ ] 换轨可撤销、重做、保存重开；文本输入框中的方向键保持文字编辑行为。
- [ ] ←/→ 选择上一/下一条，空格播放/暂停，Esc 清除选择或取消当前手势；播放和选择本身不进入编辑历史。

## Verification

1. 从基础工程准备至少三个普通说话人及两个特殊标签、同轨/跨轨重叠和相同时间条目，逐一验证选择、换轨、边界和持久化。
2. 在不同缩放和滚动位置点击字幕与拖动播放头，对照实际画面及时间字段；查看保存/导出条数确认双视图不复制数据。
3. 扩展浏览器回归并运行既有检查，记录原片定位、多视图一致性与键盘焦点的观察证据。
