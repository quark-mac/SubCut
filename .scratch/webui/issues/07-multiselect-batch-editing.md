# 07: 多选与批量编辑

Status: in-progress
Blocked by: 06
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户用 Ctrl 点选、Shift 连选或框选处理多条字幕，批量改人、整体移动时间、上下换轨和删除，且一次批量动作可以一步撤销。

## 上下文与修改范围

- 对应用户故事 34、41–45、52–53；依赖 06 的手势、坐标、边界限制和编辑提交。
- 修改 WebUI 选择模型、右侧共同属性、批量操作及相应测试。使用稳定条目身份区分数据，多个视图不增加数据份数。

## Acceptance criteria

- [ ] Ctrl 点选、Shift 连续选择及时间轴框选有效；同一条目在总览和人物轨都被框住时只进入选择集合一次。
- [ ] 修饰键点选与框选只改选择，不暂停或跳转播放头；普通单击沿用选中、暂停并定位的语义。
- [ ] 右侧展示共同属性及混合值；明确选择目标说话人后所有选中条目统一归到该标签。
- [ ] 批量横向移动保持相对时间和各条时长，到片头/片尾时整体停止，而非逐条截短或独立夹取。
- [ ] 多选 ↑/↓ 按当前说话人轨顺序整体偏移一行，保持相对轨道间距；任何一条越界则整次不执行，不循环。
- [ ] 批量鼠标移动继承单条手势的时间、归属及撤销规则，任何提交均保持有效状态；未选条目不受影响。
- [ ] Delete 可删除单选或多选条目，正文输入时优先删文字；一次批量改人、移动或删除各算一步历史。
- [ ] Esc 取消手势或清除选择；无效、取消及纯选择操作不污染历史。撤销恢复完整条目集合，保存重开保持结果。

## Verification

1. 以至少三个说话人、相同时间和重叠条目构造工程，验证三种多选方式、双视图去重及多选时播放头稳定。
2. 执行跨轨整体移动、越界拒绝、全归同一人、片头片尾时间约束和删除；通过 UI 与公开工程读取结果确认每条仅变更一次。
3. 验证批量操作的一步撤销/重做、输入框焦点及自动保存；运行回归和相应构建检查并记录结果。
