# 02: 可撤销编辑与可靠自动保存

Status: ready-for-agent
Blocked by: 01
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户在右侧编辑正文、毫秒起止时间和说话人归属，能够撤销/重做，看到准确的自动保存状态，并在保存失败后重试而不丢失编辑。

## 上下文与修改范围

- 对应用户故事 32、51–56、61；前置 01 提供工程闭环及公共测试入口。
- 修改 WebUI 编辑状态、表单、工程保存接口、持久化与相应测试。说话人归属使用开放标签；完整人物管理由后续任务提供。
- 保存对象是独立工程；条目和说话人稳定身份与显示名称、导出序号分离。

## Acceptance criteria

- [ ] 正文、时间、归属可编辑；选择或输入普通说话人名称后得到有效引用，`?`、`NONSPEECH` 保持各自语义。
- [ ] 无效正文或时间在对应字段给出原因，不提交无效工程；修改时间不推移其他字幕。
- [ ] 时间轴工具栏提供撤销/重做按钮，Ctrl+Z / Ctrl+Shift+Z 有效；一次连续文字编辑算一步，时间和归属修改亦可恢复。
- [ ] 保存不清空会话内历史；重开工程开始新历史；撤销后新编辑清除旧重做分支，无效或取消操作不制造历史步骤。
- [ ] 文本输入状态下方向键、空格、删除与撤销优先处理文字；结束输入后整次修改可从工程历史撤销。保存/导出先提交有效输入，非法草稿明确阻止操作。
- [ ] 编辑提交后短暂延迟自动保存，Ctrl+S 立即保存；状态区区分保存中、已保存、保存失败，已保存只对应确认落盘的版本。
- [ ] 保存具备修订校验及原子写入；较早响应不能把较新编辑标为已保存或覆盖较新状态，版本冲突有明确结果。
- [ ] 保存失败保留可编辑的当前状态并允许重试；磁盘保留最后完整版本，重试成功后重开得到最新结果。

## Verification

1. 浏览器中连续修改正文、时间和人物，逐步撤销/重做，验证输入焦点、保存后撤销以及重开历史重置。
2. 通过公共 HTTP 请求及可控故障验证修订冲突、延迟响应、保存失败和重试；检查磁盘状态与界面保存状态一致。
3. 运行前置任务建立的回归入口及改动相关构建/编译检查；将命令、结果和失败恢复证据记录到 Comments。
