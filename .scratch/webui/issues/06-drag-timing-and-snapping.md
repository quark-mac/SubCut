# 06: 字幕拖动、边界调整与吸附

Status: ready-for-agent
Blocked by: 04
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户从总览或说话人轨拖动字幕调整时间和归属，拉动边缘修正时长，选择是否吸附到播放头或其他字幕边界；一次手势可一步撤销。

## 上下文与修改范围

- 对应用户故事 31–32、35–37、45、52；依赖 04 的坐标、共享条目和历史联动。
- 修改 WebUI 时间轴手势、编辑提交、校验与相应测试。此任务先完成单条字幕的可用鼠标编辑。
- 原片时间与毫秒精度是数据基准，屏幕像素及缩放只是交互表示。

## Acceptance criteria

- [ ] 横向拖动改变起止时间并保持时长；边缘拖动改变开始或结束，保持媒体范围内的正时长。
- [ ] 纵向拖动改变说话人且时间不变；斜向拖动同时改变时间和归属，作为一次提交和一步历史。
- [ ] 从总览与说话人视图操作的是同一条目，释放后右侧、另一视图及保存结果一致；拖向总览不清空归属。
- [ ] 时间边界限制在媒体范围内；合法重叠保留，其他条目不被自动移动、裁剪或删除。
- [ ] 吸附按钮可开关，目标为播放头及字幕边界；关闭后可自由微调并在时间字段看到毫秒结果。
- [ ] 在不同缩放和滚动位置，拖动结果与刻度一致；未命中有效归属目标不能写入无效说话人引用。
- [ ] 一次完整拖动仅产生一步撤销，拖动预览不反复持久保存中间状态；Esc 取消回到手势前状态且不增加历史。
- [ ] 有效提交触发已有自动保存，撤销/重做和重开工程保持一致。

## Verification

1. 浏览器分别执行横向、纵向、斜向及两端边界拖动，在至少两个缩放等级和滚动位置比较实际时间与归属。
2. 测试吸附开关、片头片尾、最小时长、重叠及 Esc 取消；保存前后检查未选中字幕未变化。
3. 每种手势用一次撤销恢复，重做后保存重开；运行相关回归与构建检查并记录证据。
