# 12: 时间轴波形与缩略图

Status: ready-for-agent
Blocked by: 04, 11
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户在锁定视频轨中看到与原片时间一致的音频波形和画面缩略图，缩放、滚动时仍可用来定位台词；生成有进度且结果可缓存复用。

## 上下文与修改范围

- 对应用户故事 29–30、63；04 提供时间轴坐标和视口，11 提供媒体任务、源身份和缓存语义。
- 修改 WebUI 媒体派生任务、缓存与视频轨渲染及测试；波形和缩略图仍位于视频轨内部。

## Acceptance criteria

- [ ] 从实际媒体生成音频波形和按时间采样的缩略图，派生产物包含可确定的时间定位信息。
- [ ] 生成操作复用媒体任务的状态、进度、失败及缓存规则，UI 能看到生成过程，完成后资源和时间轴更新。
- [ ] 波形及缩略图绘制在锁定视频轨中，不改变视频、总览、说话人的轨道层级或原片时间。
- [ ] 缩放和水平滚动后，同一原片位置的声音峰值及画面采样仍正确对齐播放头、刻度和字幕；仅渲染当前需要的内容。
- [ ] 原片与预览副本保持一致的定位结果，不能把裁剪或压缩后的时间当原片时间；无音轨的素材有合理空波形状态。
- [ ] 重开工程可复用有效缓存；原媒体变化或生成参数变化后旧缓存失效，失败产物不被显示为完成。
- [ ] 派生产物生成、加载、缩放和滚动不修改字幕或编辑历史，失败不会阻断已有字幕编辑及保存。

## Verification

1. 使用已知时刻出现音频脉冲和画面变化的素材，真实生成波形及缩略图，并在浏览器多个缩放/滚动位置对照标记。
2. 检查可直接播放素材与预览副本、无音轨素材、缓存复用和失效；通过公共任务状态和实际产物验证生成结果。
3. 检查生成前后工程字幕未变化，运行相关浏览器/HTTP/媒体回归及构建检查并记录证据。
