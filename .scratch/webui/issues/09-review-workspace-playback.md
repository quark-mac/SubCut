# 09: 逐句试听与校对工作区完善

Status: ready-for-agent
Blocked by: 04
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户搜索目标台词、调整面板、双击逐句试听或循环慢放，在视频上查看当前工作字幕，同时保持手动编辑选择不被播放过程打断。

## 上下文与修改范围

- 对应用户故事 15–17、23–28；依赖 04 的共享时间轴与选择/播放分离。
- 修改 WebUI 工作区布局、播放器控件、字幕叠加、右侧列表及测试。人物管理、波形等能力由各自任务扩展现有区域。

## Acceptance criteria

- [ ] 保持深色中文三面板布局，上部面板宽度及上下分区高度可拖动调整；撤销/重做仍位于时间轴工具栏。
- [ ] 右侧具有字幕/说话人页签；字幕列表支持文字搜索及按人物筛选，筛选改变显示不改变工作字幕或历史。
- [ ] 普通单击暂停并定位；双击从起点播放到终点自动停止，提供当前字幕循环试听与明确的退出控制。
- [ ] 提供时间跳转、播放/暂停、0.5～2 倍速；操作后播放头、实际画面与字幕高亮同步。
- [ ] 视频叠加当前已提交工作字幕，可独立开关字幕和说话人名称；同时间多条字幕错开显示，使用当前标签。
- [ ] 播放过程中高亮可变化，但右侧编辑选择不被抢走；文字提交后叠加与列表更新。
- [ ] 输入框焦点、←/→ 导航、空格及 Esc 沿用既定语义；视图调整与播放控制不进入编辑历史。
- [ ] 帮助内容可查到当前已实现的快捷键；已交付的菜单和工具操作能从工作区实际触发。

## Verification

1. 浏览器逐条双击、循环、调速、跳转并检查短句终点；播放中编辑另一条，确认选择与高亮分离。
2. 对多行及重叠字幕检查叠加、人物名称开关和文本更新；搜索/筛选后操作条目，确认实际工作字幕集合不变。
3. 调整面板并检查主要控件可用，运行回归与前端类型/构建检查，在 Comments 记录真实播放和布局观察。
