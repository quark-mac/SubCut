# 03: 多格式字幕交换与整体替换

Status: ready-for-agent
Blocked by: 02
Spec: [WebUI 字幕与说话人编辑器](../spec.md)

**What to build:** 用户通过导入预览明确选择字幕解释方式，导入现有项目或 MOSS 结果进行校对，导出所需格式；在工程中整体替换字幕后可以一键撤销。

## 上下文与修改范围

- 对应用户故事 10–14、46、57–61；依赖 02 的可撤销编辑和保存。
- 修改 WebUI 字幕格式适配、导入/导出交互、公共服务边界与测试。现有 SRT 解析器要求说话人前缀，普通 SRT 必须通过适当适配处理。
- 来源索引、MOSS 段 ID、工程条目身份和导出序号是不同概念。

## Acceptance criteria

- [ ] SRT 预览可选普通、本项目方括号标签、MOSS 冒号前缀三种模式；普通模式保留方括号和冒号正文，项目模式解析说话人及已知元标签，MOSS 模式按明确选择解析。
- [ ] normalized JSONL 导入保留正文、说话人、元标签和原来源索引；秒制输入转换为毫秒，非法值及换算后零时长报告错误。
- [ ] MOSS JSON 接受 id/start/end/speaker/text 顶层数组；人物 ID 原样建轨，导入 ID 留作来源，不虚构显示名映射或 ASS 来源索引。
- [ ] `?`、`NONSPEECH`、组合标签及其他名称保留原意；多行和合法时间重叠不丢失。
- [ ] 全部解析和校验成功后才应用导入；畸形条目给出位置、字段、原因，失败不部分替换工作字幕。
- [ ] 整体替换的字幕、来源和说话人引用作为一个编辑操作提交，撤销完整恢复原状态，重做及保存重开结果一致。
- [ ] 四种导出均可从 UI 触发：默认干净说话人 SRT、普通 SRT、项目 JSONL、MOSS JSON；导出快照不混入稍后的编辑。
- [ ] SRT 确定性排序、连续编号，元标签由显式选项保留；JSONL 保留来源和元标签；MOSS 输出五字段数组、唯一段 ID 和当前标签。
- [ ] 资源区显示真实导出产物；无法表达完整工程信息的格式不用于替代完整工程保存。

## Verification

1. 使用含 `[笑声]`、冒号、多行、未知标签、组合标签、元标签和重复时间的夹具，分别检查三种 SRT 模式及两个结构化格式。
2. 浏览器整体替换、撤销、保存重开，再导出四种格式；通过实际文件确认来源索引未被重新编号改写、MOSS 输出可重新导入。
3. 通过 HTTP 验证原子导入、非法输入及导出快照；运行已有测试入口与相应类型/构建/编译检查，并在 Comments 记录证据。
